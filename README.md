# Pagefold

面向 Windows 的现代桌面文件资源管理器，中文名「叠页」，
界面按设计稿实现（设计稿未随仓库发布），
Fluent Design / Windows 11 原生观感，参考 Files 项目。

---

## 已实现能力

- **主窗口四区块**：标签条、命令条、内容区（侧边栏 / 主区 / 预览面板三栏）、底部状态栏。
  窗口以 `appears_transparent: true` 创建，系统边框隐藏；主题切换与最小化 / 最大化 / 关闭
  都在标签条右端，动作交回系统（`WindowControlArea`），不自己实现窗口缩放逻辑。
  标签与这组按钮之间那段空白是**窗口唯一的拖动区域**——原来承担拖拽的品牌栏已整条删除，
  所以那一段留了 32px 最小宽度，保证标签铺满时窗口仍抓得住。
- **多标签页**：新建 / 关闭 / 切换 / **拖拽排序** / **中键关闭**，每个标签独立维护路径、
  前进后退历史、视图状态与扫描代数。关闭当前标签时优先落到右侧邻居，关闭最后一个标签时
  重置为新标签。标签条右端有「＋」与「⋯」两个按钮：「＋」新建，「⋯」弹出标签页操作菜单
  （新建 / 重新打开关闭的标签页 / 关闭其他 / 关闭右侧）；标签右键弹出同一份菜单，
  且「关闭其他 / 关闭右侧」以被右键的标签为参照。
- **左侧导航栏**：快速访问（由 `SHGetKnownFolderPath` 定位，正确处理被重定向过的文件夹）、
  **回收站**（虚拟位置，只读浏览，见下）、
  「此电脑」分组（可折叠，子项为驱动器）、底部磁盘容量档位（名称 + 百分比 + 容量条 + 剩余/总量）。
  选中项为强调色浅底 + 强调色图标；展开 238px、折叠 48px，切换带 180ms 缓动。
- **地址栏**：面包屑逐级可点击跳转，层数过多时保留首段与尾部、中间折叠为省略号；
  窄屏（≤720px）只保留首段与末段。点击空白处切换为可编辑地址栏，
  **回车提交、失焦取消**；右侧「复制路径」写入系统剪贴板（`ClipboardItem`）并弹出通知。
- **搜索框**：点击进入编辑态，**输入即筛选**当前文件夹（大小写不敏感的名称匹配），
  无结果时给出专门的空状态；清除按钮一键回到完整列表。
- **双视图**：图标网格（按行虚拟化，单元格 122/152/192 三档，1:1 缩略图底板 + 两行名称）
  与详细信息表格（固定表头 + 按行虚拟化，列宽按断点退让，点击列名排序并显示箭头）。
  两个视图都支持**双击文件夹进入**（文件的双击暂不处理，见 [路线图](./docs/ROADMAP.md)）。
- **选中与预览**：单击选中、`Ctrl` 切换、`Shift` 区间、**框选（按住左键拖拽）**、表头勾选框全选；
  列表上方是**常驻**的选中条（数量 / 合计大小 / 动作；没有选中时显示「未选择项目」
  且动作全部禁用并说明原因），右侧预览面板（单项显示名称、类型、大小、修改时间、
  位置；多项显示数量与合计）。
  两条栏**共用同一个高度令牌**（`fm_views::metrics::BATCH_BAR_HEIGHT`），因此左右两栏的
  表头始终等高。设计稿是把选中条整条 `hidden` 掉，这里刻意改成常驻：否则每点一次
  条目，下面的列表就会上下跳一次，那种跳动的代价比省下的 40px 大得多。
- **右键上下文菜单**：详情行、图标单元格、内容区空白处各有一套。条目菜单按类型动态生成
  （驱动器隐藏整组写操作、多选时文案带数量与「批量」、回收站里只给「属性」、
  空白处菜单在「此电脑」与回收站里不显示新建与粘贴）；
  定位与边缘吸附、`Esc` 与点击外部关闭、上下键切换与回车确认由组件库的 `PopupMenu` 提供，
  没有自己造弹出层。
- **键盘快捷键**：`Ctrl+T` / `Ctrl+W` / `Ctrl+Shift+T`（新建 / 关闭 / 恢复标签）、
  `Ctrl+,`（打开设置）、`Ctrl+L`（聚焦地址栏）、`Ctrl+1` / `Ctrl+2` / `Ctrl+3`（列表视图 / 图标视图 / 切换主题）、
  `Alt+←` / `Alt+→`（后退 / 前进）、`Backspace`（上一级）、`F5`（刷新）、
  `Ctrl+A` / `Ctrl+C` / `Ctrl+X` / `Ctrl+V`（全选 / 复制 / 剪切 / 粘贴）、
  `Ctrl+Z`（撤销）、`F2`（重命名）、`Delete`（移到回收站）、
  `Shift+Delete`（永久删除）、`↑` / `↓`（移动焦点，`Shift` 扩选）、
  `Enter`（打开）。文本输入框聚焦时自动让位；右键菜单里也显示对应的键位提示。
- **文件写操作**：新建（文件夹 / 文本文档 / Markdown 文档）、复制、剪切、粘贴、重命名、
  移到回收站。入口有三处且**共用同一套动作定义**：内容区右键菜单、选中条的动作组、
  命令条右端的「新建」下拉。重命名是**内联**的（在行内把名称换成输入框、预选主干不含扩展名、
  回车或失焦提交）；**新建之后（文件夹与文件都一样）立即进入重命名**，并会把新条目
  滚进可视区（它的位置由排序决定，可能在视野之外）；
  移到回收站前有一个把确定按钮染成危险色的确认框。操作结果与失败原因都以 toast 提示，
  出现在左下角（与设计稿的 `.toasts` 同侧同距）。
  设计与取舍见 [设计与架构](./docs/DESIGN.md)；仍未做的部分见 [路线图](./docs/ROADMAP.md)。
- **设置页（标签内页面）**：`Ctrl+,`、命令条右端按钮、标签条「⋯」菜单三个入口，
  打开的是同一类标签——因此它天然支持关闭、恢复、拖拽排序，不额外维护窗口生命周期。
  三节分组：外观（主题 / 密度 / 图标缩放 / 显示扩展名）、
  视图（预览面板 / 隐藏和系统文件 / 默认视图）、
  关于与快捷键（版本、配置文件路径可复制、完整键位表）。**改动立即生效并写盘，没有「应用」按钮**。
- **深浅色主题与外观档位**：命令条一键切换主题；状态栏三档缩略图缩放
  （**只作用于图标视图**，详细信息视图下置灰并提示按 `Ctrl+2` 切换）；
  界面密度（紧凑 / 标准 / 宽松）与「显示扩展名」既可在设置页改，也可直接改配置。
  全部持久化到 `%APPDATA%\pagefold\config.json`。
- **会话恢复**：退出后重启恢复标签数量、顺序、各自的前进后退历史、激活标签与视图模式，
  存于 `%APPDATA%\pagefold\session.json`（与 `config.json` 分开）。文件损坏、版本不符或
  历史为空时整体回退为单个默认标签，不阻断启动；命令行给了路径时**不读会话**，
  因为「打开这个文件夹」是此刻的明确意图。
- **详情表列宽拖拽**：拖动表头分隔线调整「修改日期 / 类型 / 大小」，拖动只改样式不动数据。
  断点仍决定列**是否显示**，偏好只覆盖可见列的**宽度**，并按内容区宽度收敛，
  名称列至少保留 180px。偏好写入 `config.json` 的 `detail_columns`，越界值读取时也会被夹回区间。
- **预览面板「在列表中定位」**：选中项滚出视野后（排序、筛选或键盘导航之后），
  点一下即可滚回那一行并保持选中；图标视图与详情视图行为一致。
- **目录变更自动刷新**：当前目录被外部程序改动（下载完成、解压、别的窗口删文件）后
  自动重新扫描，无需按 `F5`。实现是 `ReadDirectoryChangesW` 单层监听 + 400ms 轮询：
  事件只累加一个计数器，由 UI 决定何时刷新，因此解压大文件不会把渲染打满。
  监听听不到的目录（权限不足）只记 debug 日志，不影响打开。
- **重复启动的位置转发**：已有实例在运行时 `pagefold.exe D:\some\dir` 不再只激活窗口，
  而是通过命名管道把位置交给主实例，由它**新开一个标签**并跳过去。
  管道未就绪或无参数时退回「只激活窗口」。
- **隐藏与系统文件**：默认按资源管理器习惯隐藏带 `Hidden` / `System` 属性的条目，
  可在设置页打开。过滤发生在**载入列表时**，因此下标、选中集与右键菜单始终一致。
- **系统文件图标**：按扩展名向 shell（`SHGetFileInfoW`）取 32×32 图标，
  图标网格、详情表与预览面板显示的都是系统真实图标（文件夹也是）；
  取不到时退回内置 SVG。图标按扩展名缓存，一屏 500 个 `.txt` 只会提取一次。
  驱动器与符号链接仍用内置图标——它们要真实盘符/链接目标才能取到正确图像。
- **永久删除（`Shift+Delete`）**：不进回收站，走独立的确认框（「此操作无法撤销」）。
  逐条回执；含只读文件的目录会先清属性再删，不会因为一个只读文件整批失败。
  右键菜单里它与「移到回收站」是**两个独立项**，不是同一个动作的两个变体。
- **回收站可还原 / 清空**：进回收站右键条目「还原」即搬回原位置（原名被占用时自动改名
  为 `名称 (2).ext`）；空白处右键「清空回收站…」二次确认后清空。回收站条目不能直接打开，
  双击会提示先还原。
- **双击用默认程序打开**：双击文件即交给系统默认应用（`ShellExecute`），
  `Enter` 键同理；目录仍在本窗口内进入，不会新开一个资源管理器窗口。
- **拖出文件**：把条目从列表拖出窗口边界，即可拖到资源管理器 / 桌面等支持文件拖放的位置；
  拖已选中的条目带走整个选中集，拖未选中的只带它自己。窗口内拖动仍是框选，行为不变。
- **拖入文件**：从资源管理器 / 桌面 / 其它程序把文件或文件夹拖进内容区即可复制到当前目录。
  拖动经过时会高亮内容区，松手后走与粘贴同一条管线（右下角进度、可取消、`Ctrl+Z` 可撤销）。
  GPUI 的拖放事件只带路径、不带「复制还是移动」，因此**一律按复制处理**——猜错的代价是丢数据。
- **跨程序剪贴板**：`Ctrl+C` / `Ctrl+X` 会同时写进系统剪贴板（`CF_HDROP`），
  因此在资源管理器里能直接粘贴；反过来在资源管理器里复制文件，回到本程序 `Ctrl+V` 也能粘。
  剪切（`Ctrl+X`）带 `Preferred DropEffect = 移动`，对方会按「移动」处理。
  应用内剪贴板仍然是权威来源，写系统剪贴板失败时降级为「只能在本程序内粘贴」。
- **传输进度与取消**：复制 / 移动时右下角出现进度卡（已处理文件数、当前文件），
  点「取消」会在**当前文件写完之后**停下，不产生半截文件；取消后剪贴板保留、已完成的条目仍可撤销。
- **批量重命名**：多选后右键「批量重命名…」，按「前缀 + 起始序号」生成新名字，
  可保留或丢弃扩展名；面板里实时预览每一行的新旧名称，与现有条目撞名会标红并禁止执行。
  整批算**一步**撤销（`Ctrl+Z` 一次全改回）。
- **撤销（`Ctrl+Z`）**：重命名、新建、复制粘贴、剪切粘贴、批量重命名都可以撤销（栈深 50 步），
  空白处右键菜单会直接写出「撤销 重命名「x」」。撤销本身不入栈（没有重做）。
  **移到回收站不在此列**：它的逆操作是「还原」，需要回收站的写能力（与清空一起做），
  与其做一半，不如先不做。
- **大目录流式扫描**：后台线程扫描与排序，结果按 512 条分批并入视图；
  `generation` 计数保证快速切换目录时旧结果不会错乱，扫描中取消会立即停止 IO。
  列表渲染按视口虚拟化，复杂度与目录条目数无关。
- **单实例**：同一登录会话内只保留一个进程。重复启动时新进程会激活已有窗口后立即退出，
  不会堆积多份实例。实现走命名互斥体 + `SetForegroundWindow`，**不写任何注册表**。
- **「此电脑」驱动器总览**：侧边栏顶部可进入，以卡片形式列出全部驱动器
  （图标 + 类型 + 剩余容量 / 总容量 + 占用条）。虚拟位置由 `Location` 枚举表达，
  从类型上就不可能被当成目录送去扫描。
- **回收站（只读浏览）**：侧边栏「访问位置」的最下面进入。直接读各卷
  `$Recycle.Bin\<SID>\` 里成对的 `$I`（元数据）/ `$R`（内容）——**不走** Shell 命名空间那套 COM，
  因为这里需要的只是「删了什么、多大、什么时候删的」。列表显示**原文件名**、大小与**删除时间**，
  可排序、可搜索；读不到的卷与损坏的 `$I` 一律跳过，不让整个视图报错。
  **不做还原与清空**：那两条是写操作。回收站里的条目也不能按路径导航
  （`path` 指向受保护的 `$Recycle.Bin` 内部），双击、右键「打开」与预览面板的「打开」
  三处都做了拦截。
- **`Win+E` 接管**：由独立的热键宿主进程（`pagefold.exe --hotkey-host`）用低层键盘钩子
  （`WH_KEYBOARD_LL`）拦截 `Win+E`，激活已有窗口或拉起一个新窗口，
  初始位置为「此电脑」——与资源管理器 `Win+E` 的语义一致。
  宿主不启动 GPUI、不占 GPU，常驻内存只有几 MB；
  **本项本身不写任何注册表**（文件夹接管是另一个独立开关），
  托盘菜单「退出」即彻底交还系统。
- **文件夹接管**：两个彼此独立的开关，入口都在托盘菜单里，带勾选态反映真实状态。
  - 「在文件夹右键菜单中显示『用 Files 打开』」——不改变任何默认行为，零风险；
  - 「设为文件夹默认打开程序」——覆盖 shell 的文件夹打开处理器，桌面双击文件夹、
    以及其他程序调 `ShellExecute`（浏览器的「在文件夹中显示」、下载完成的「打开文件夹」）
    都会打开 Files。

  两项都写在 `HKCU\Software\Classes`（用户级，不需要管理员权限），
  因此**还原只需删掉这些键**——机器级 `HKLM` 里的原始值原封不动，行为自动恢复。
  还原入口有三个，彼此等效：托盘菜单「恢复资源管理器为默认」、
  命令行 `--restore-folder-integration`、以及程序目录旁的 `restore-explorer.bat`
  （最后一个是程序本体损坏时的自救通道，见下）。

## 安装

从 [Releases](https://github.com/zzhkhyl/pagefold/releases) 下载
`Pagefold-<版本>-x64-setup.exe`，按向导安装即可（用户级安装，全程不弹 UAC）。
安装包由 GitHub Actions 在推送 `v*` tag 时自动编译并发布（含 `SHA256SUMS.txt`），
维护者流程见 [`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md) 的「CI 自动发布」。
尚未发布安装包时，可直接从源码构建。

也可以从源码构建：

```bash
cargo build --release -p fm-app
# 产物：target/release/pagefold.exe
```

构建环境、打包与依赖的详细说明见 [`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md)。
